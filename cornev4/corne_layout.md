# Corne v4.1 — Layout

Layers 0–2 of the `cornev4` keymap (source: [`keymap.c`](keymap.c), synced from `corne-wired/layout.vil`).

| Layer | Name | How to activate |
|-------|------|-----------------|
| 0 | Base QWERTY | Default |
| 1 | Numbers / Navigation | Hold `MO1` (left middle thumb) |
| 2 | Function / Nav | Hold `MO2` (right middle thumb) |

`TRNS` = transparent (falls through to the layer below).

## Layer 2 — Function / Nav

```
┌──────┬──────┬──────┬──────┬──────┬──────┬──────┐   ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┐
│ TRNS │  F1  │  F2  │  F3  │  F4  │  F5  │ F11  │   │ F12  │  F6  │  F7  │  F8  │  F9  │ F10  │ PSCR │
├──────┼──────┼──────┼──────┼──────┼──────┼──────┤   ├──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│ CAPS │ LEFT │ DOWN │  UP  │ RGHT │ TRNS │ TRNS │   │ TRNS │ TRNS │  U   │ LEFT │  I   │ F11  │ DEL  │
├──────┼──────┼──────┼──────┼──────┼──────┼──────┘   └──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│ TG3  │ TRNS │ BSPC │ TRNS │ TRNS │ SLEP │                 │ F12  │  J   │ RGHT │  K   │ END  │ HOME │
└──────┴──────┴──────┼──────┼──────┼──────┤                 ├──────┼──────┼──────┼──────┴──────┴──────┘
                     │ C+A  │ C+RA │ MO0  │                 │ ENT  │ TRNS │ TRNS │
                     └──────┴──────┴──────┘                 └──────┴──────┴──────┘
```

- `C+A` = `LALT(KC_LCTL)` (Left Ctrl + Left Alt)
- `C+RA` = `RCTL(KC_RALT)` (Right Ctrl + Right Alt / AltGr)
- `TG3` toggles Layer 3 (RGB controls + `QK_BOOT`)
