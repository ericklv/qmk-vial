# Lily58 Pro R2G — Layout

Layers of the `lily58pro` keymap (source: [`keymap.c`](keymap.c)). Layers 1–2 mirror the Corne v4.1 ([`corne_layout.md`](../cornev4/corne_layout.md)) for shared muscle memory. Rationale: [`layout_proposal.md`](layout_proposal.md).

| Layer | Name | How to activate |
|-------|------|-----------------|
| 0 | Base QWERTY | Default |
| 1 | Numbers / Navigation | Hold `MO1` (left thumb 2) |
| 2 | Function / Nav | Hold `MO2` (right thumb 2) |
| 3 | RGB / Media / Boot | Hold `MO1` + `MO2` (tri-layer), or `TG3` on L2 (exit with `TG3` on L3) |

`▽` = transparent (falls through to the layer below) · empty = no-op

## Layer 2 — Function / Nav

```
┌──────┬──────┬──────┬──────┬──────┬──────┐                 ┌──────┬──────┬──────┬──────┬──────┬──────┐
│  ▽   │  ▽   │  ▽   │  ▽   │  ▽   │  ▽   │                 │  ▽   │  ▽   │  ▽   │  ▽   │  ▽   │  ▽   │
├──────┼──────┼──────┼──────┼──────┼──────┤                 ├──────┼──────┼──────┼──────┼──────┼──────┤
│  ▽   │  F1  │  F2  │  F3  │  F4  │  F5  │                 │  F6  │  F7  │  F8  │  F9  │ F10  │ PSCR │
├──────┼──────┼──────┼──────┼──────┼──────┤                 ├──────┼──────┼──────┼──────┼──────┼──────┤
│ CAPS │ LEFT │ DOWN │  UP  │ RGHT │  ▽   │                 │ HOME │ PGDN │ PGUP │ END  │ F11  │ DEL  │
├──────┼──────┼──────┼──────┼──────┼──────┼──────┐   ┌──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│ TG3  │  ▽   │ BSPC │  ▽   │  ▽   │ SLEP │  ▽   │   │  ▽   │ F12  │ MUTE │ VOLD │ VOLU │ MPLY │  ▽   │
└──────┴──────┴──────┼──────┼──────┼──────┼──────┤   ├──────┼──────┼──────┼──────┼──────┴──────┴──────┘
                     │ C+A  │ C+RA │ F11  │  ▽   │   │ ENT  │ F12  │  ▽   │  ▽   │
                     └──────┴──────┴──────┴──────┘   └──────┴──────┴──────┴──────┘
```

- `H J K L` = `HOME PGDN PGUP END`: the same direction as the L1 arrows, with a bigger jump.
- `C+A` = `LALT(KC_LCTL)` · `C+RA` = `RCTL(KC_RALT)` (AltGr).
- Number row is transparent, so digits still work.

## Layer 3 — RGB / Media / Boot

```
┌──────┬──────┬──────┬──────┬──────┬──────┐                 ┌──────┬──────┬──────┬──────┬──────┬──────┐
│ BOOT │      │      │      │      │      │                 │      │      │      │      │      │      │
├──────┼──────┼──────┼──────┼──────┼──────┤                 ├──────┼──────┼──────┼──────┼──────┼──────┤
│      │      │      │      │      │      │                 │      │      │      │      │      │      │
├──────┼──────┼──────┼──────┼──────┼──────┤                 ├──────┼──────┼──────┼──────┼──────┼──────┤
│      │      │ MPRV │ MPLY │ MNXT │ VOLU │                 │      │ RGB  │ MODE │ HUE+ │ SAT+ │ VAL+ │

│ TG3  │      │      │ MUTE │      │ VOLD │      │   │      │      │ SPD+ │ SPD- │ HUE- │ SAT- │ VAL- │
└──────┴──────┴──────┼──────┼──────┼──────┼──────┤   ├──────┼──────┼──────┼──────┼──────┴──────┴──────┘
                     │  ▽   │  ▽   │  ▽   │  ▽   │   │  ▽   │  ▽   │  ▽   │  ▽   │
```

- `BOOT` = `QK_BOOT` (top-left): enters the bootloader without pressing the RESET button.
- RGB: `RGB` toggle, `MODE` next effect, `HUE/SAT/VAL/SPD ±`.
